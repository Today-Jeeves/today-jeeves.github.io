# Money Starter

Source for https://today-jeeves.github.io, a personal-finance guide site built with Jekyll and published by GitHub Pages from the `main` branch.

- Articles live in `_posts/` as `YYYY-MM-DD-slug.md`.
- Site settings, including the store link and (optional) Amazon/AdSense IDs, are in `_config.yml`.
- `AUTOMATION.md` describes how new articles are written and published.
